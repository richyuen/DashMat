# Benchmark Sample Files

These files are generated by `generate_test_data.py` and used by the
`Sample Daily File` / `Sample Monthly File` download buttons.

- `benchmark_daily_returns_2020_2025.xlsx`
- `benchmark_monthly_returns_2020_2025.xlsx`

Coverage:
- Date range: `2020-01-01` to `2025-12-31`
- 10 benchmark return series

Series and source mapping used by `generate_test_data.py`:
- `SPX` -> `^GSPC` (actual index)
- `RMID` -> `^MID` (actual index)
- `R2000` -> `^RUT` (actual index)
- `EAFE` -> `EFA` (proxy fallback)
- `EM` -> `EEM` (proxy fallback)
- `MSCIUSREIT` -> `VNQ` (proxy fallback)
- `BCAgg` -> `AGG` (proxy fallback)
- `BCHY` -> `HYG` (proxy fallback)
- `BCGAgg` -> `BNDW` (proxy fallback)
- `BCGC13` -> `SHY` (proxy fallback)

Notes:
- Several MSCI/Bloomberg benchmark histories are not directly available from the free endpoint used here.
- Proxy fallbacks are used to keep the sample files reproducible and downloadable.
